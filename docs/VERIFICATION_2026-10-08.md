# 홍보 사이트 전면 개편 검증 — 2026-10-08

사용자 직접 요청: 최신 실제 앱 화면·다운로드 중심 카피·전면 디자인 개편. 정체성은 “목표를 무조건 이루게 해주는 플래너”. 새 앱 기능이나 스토어·계정·가격 변경은 포함하지 않는다.

## 변경

- 첫 문장 “이번 목표는, 끝까지.” / “Big goals. Done daily.”. 목표 → 오늘 실행 → 완료 순서의 한영 설명.
- 밝은 바탕, 선명한 블루, 큰 제목, 실제 화면을 이용한 기기 연출. 모바일 하단 양 스토어 링크.
- TDL 계획 예시 3종(독서·운동·공부), 알림·일정 밀기, 돌아보기, iPad 화면, 기간 일정 수정/삭제·프로젝트 즉시 선택.
- 무료/Pro 구분 및 통계 최소 표본, iOS 전용 iCloud·잠금 화면 위젯 조건. 과거 고정 가격·과도한 알림 보장 문구 정리.
- 한영 실제 앱 캡처16개, 원본 해시 보존. 1200×630 JPEG 링크 미리보기와 편집 가능한 HTML 원본.

## 실제 실행한 확인

- JavaScript `node --check`: 통과. Git `diff --check`: 통과.
- HTML: H1 1개, 중복 ID 없음, 내부 앵커7개 유효, 이미지 대체 텍스트·화면 비율 확인. 원본 캡처16개 해시 일치.
- 브라우저: 320/390/768/1280px × 한국어/영어 총8조합, 가로 넘침 없음·이미지 언어 전환 확인.
- 독서/운동/공부 예시 전환, 언어 전환 후 예시 유지, 새로고침 후 언어 설정 유지 확인.
- FAQ4개 키보드 Enter 열기/닫기 확인. 브라우저 오류·경고0건(검사 시점).
- PC·모바일 첫 화면, 기능 이미지, 돌아보기·iPad 영역 시각 검토. PC 배경·768px 기기 넘침과 태블릿 이미지 설명 겹침을 발견해 수정 후 재검사.

## 미확인·남은 범위

- 실제 인스타그램 미리보기 캐시/인앱 브라우저, 실제 기기의 모든 브라우저 조합, 설치 전환율·광고 성과는 미검증.
- 앱 코드는 바꾸지 않았으며 앱 테스트·빌드·스토어 제출은 실행하지 않음.
- 분석 도구·광고 픽셀·외부 폰트·유료 서비스는 추가하지 않음. 실제 매출·비용·사용자 제공 작업시간은 미확인.
- 공개 배포 결과와 최종 커밋은 앱 저장소 HANDOVER/STATUS/MASTER 현황에 기록한다.
